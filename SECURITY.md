# Security and privacy

Do not report private user content in a public issue. If personal journals, photos, credentials, signing material, or profile data are committed accidentally:

1. Make the repository private immediately.
2. Revoke any exposed credentials.
3. Remove the material from the current branch.
4. Rewrite Git history to purge the affected objects.
5. Rotate or replace copies that may have been shared elsewhere.

The application is designed for local-only journal storage and does not require a backend.
